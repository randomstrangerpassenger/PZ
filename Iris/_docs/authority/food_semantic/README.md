# Food Semantic Authority

This directory contains additive, machine-readable implementation proposals for
the DVF 3-3 food semantic facts authority reconstruction.

The contracts define a closed semantic schema, exact evidence allowlist,
deterministic R3 rules, signal-to-fact mappings, proposition licensing, curation
policy, and the authority boundary between implementation previews and approved
facts.

Nothing in this directory is current fact authority merely because it exists.
The implementation attempt does not modify current facts, the current input
manifest, rendered output, Lua/runtime chunks, or packaged payloads. Semantic
approval, external implementation review, non-current successor sealing, and
Registry-owned current adoption remain separate post-implementation actions.
