# Public Text Quality Acceptance Policy

> 상태: G4 fresh candidate-independent policy candidate successor
>
> 공식 ratification: false
>
> 권한 효과: none
>
> policy closure: not started

이 문서는 remediation target을 고정하는 development foundation 설명이다.
v2 foundation successor는 v1의 metric/denominator, policy, detector와
runner/validator 의미를 재사용하되 G0~G3 및 current facts/manifest exact
identity를 추가로 결속한다. 공식 policy는 immutable naturalization handoff
이후 별도 Publish Boundary attempt의 owner metric-level ratification과 detached
seal을 거쳐야 한다.

## Current payload candidate mapping

- `coverage_quality_weak`: blocking, numerator `== 0`
- `missing_any_required_section_row`: blocking, numerator `== 0`
- `missing_required_section_occurrence`: advisory debt, numerator `== 0`이어야 debt-free
- adequate/strong, section breakdown, unadopted: non-claim

## Naturalization candidate mapping

semantic preservation failure, unsatisfied required role, equivalence proof failure, compiler-invalid pattern, required-denominator human blocker는 blocking이며 numerator `== 0`을 요구한다.

raw detector mapping은 foundation contract의 `detector_mapping_candidate`에 exact integer/rational threshold로 기록한다. semantic duplication, internal abstraction leakage, empty/filler sentence는 blocking zero-tolerance다. identity repetition, paragraph fragmentation, passive translationese는 advisory debt zero target이다. repeated skeleton concentration은 exact ratio `<= 1/20`을 debt-free boundary로 사용한다.

이 threshold는 current payload나 future candidate 결과를 읽지 않고 정한 v1 remediation contract다. 결과를 본 뒤 같은 version의 threshold를 고치지 않는다.

## State machine

```text
technical blocker > 0 -> blocked
else effective blocking finding > 0 -> blocked
else advisory debt > 0 or active waiver > 0 -> deferred_internal_debt
else -> accepted
```

G4 foundation은 이 state machine으로 official disposition을 발행하지 않는다.
